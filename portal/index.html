📶 Network Architecture: "Connecto Patronuum Ad-Free"

To guarantee your main home Wi-Fi stays at 100% full speed with zero latency overhead for gaming and work, your main network remains untouched. Use this dedicated setup for ad-free browsing:

Step 1: Main Wi-Fi (Untouched)
Devices on "Connecto Patronuum" use normal router DNS. No proxying, no filtering, fastest possible ping for games and latency-critical apps.
Step 2: Ad-Free Wi-Fi (Pi-hole)
Create a Guest/Secondary SSID on your router named "Connecto Patronuum Ad-Free" and set its DNS server to 192.168.1.107.
Step 3: Remote Tailscale Access
Any device away from home can set Tailscale DNS to 100.88.71.2 to get full ad-blocking on cellular data worldwide!
